# Rhino Workbench

Three skills that let an AI agent model in Rhino 8: objects and buildings from text and dimensions (rhino-model), facades and whole buildings from photos (rhino-facade), and the connection doctor (rhino-doctor). The agent writes a compact JSON spec; the free, MIT-licensed claude-rhino-plugin runtime on the user's PC turns it into clean, layered solids in one call.

Needs Rhino 8 with McNeel's Rhino-MCP-Platform and the runtime from https://github.com/filippovisentin/claude-rhino-plugin connected to the same agent (runtime.md explains how). The runtime's optional facade detector and its weights are not part of this pack.
