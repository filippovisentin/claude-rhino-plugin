Claude Code plugin / field notes v0.2.1 · tested on Windows

Talk to Rhino
from Claude.

Connects Claude Code to Rhino 8 and Grasshopper. Describe what you want in plain words. Claude builds the geometry, checks it and shows you the viewport.

§ 01

What it does

three jobs
01.1

Connects by itself

Finds McNeel's Rhino MCP router on your computer. No paths to copy, and Rhino updates don't break it.

01.2

Lets Claude see

Viewport captures reach Claude as real images, so it can look at the model, spot mistakes and fix them.

01.3

Explains problems

The rhino-doctor check says what's wrong and how to fix it, in plain words.

§ 02

How it works

all local
Fig. 1Everything runs on your computer. The plugin starts McNeel's router and passes messages through; the modelling tools come from Rhino.
§ 03

Get started

about five minutes
1

Install the Rhino side

In Rhino 8 type _PackageManager, install Rhino-MCP-Platform, restart Rhino.

2

Add the plugin

Needs Node.js 18 or newer.

$ claude plugin marketplace add \
    filippovisentin/claude-rhino-plugin
$ claude plugin install rhino@claude-rhino
3

Say hello

With Rhino open, start a new Claude session and ask “What's in my Rhino document?”

§ 05

If something goes wrong

run the doctor

Ask Claude “Rhino isn't connecting”, or run the check yourself from the plugin folder.

$ node scripts/doctor.mjs
[OK  ] package  0.3.0 (Rhino 8.0)
[OK  ] mcp      router 0.3.0, 32 tools
[OK  ] rhino    localhost:10500
You seeWhat to do
packageFAILInstall Rhino-MCP-Platform from _PackageManager, restart Rhino.
configWARNAnother Rhino MCP server is registered, often the community rhinomcp. Remove it with claude mcp remove.
rhinoWARNNo Rhino running. Open Rhino 8, or let Claude start one.
images as textThe session predates your update. Start a new session.
§ 06

Good to know

safety

It can run code

Python, C# and Rhino commands are part of the toolset. Keep permission prompts on unless you trust the task.

Unknown files

Text inside a model (object names, notes) reaches Claude. Treat models from strangers as untrusted input.

Secrets stay private

The doctor never prints other MCP servers' arguments or environment, where API keys may live.
