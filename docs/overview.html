A plugin for Claude Code / field notes free · works on Windows

Talk to Rhino
from Claude.

Type what you want, like “make a 22 cm cylinder split into four parts”, and Claude models it in Rhino for you. It can also look at your viewport and tell you what it sees.

§ 01

What you can do with it

in plain words
01.1

Model by describing

Ask for shapes, layers, joints or a Grasshopper definition in a sentence. Claude does the clicking.

01.2

Get a second pair of eyes

Claude can take a picture of your viewport, look at it, and point out or fix what looks wrong.

01.3

Help when it won't connect

If Claude can't reach Rhino, it runs a check and tells you, step by step, how to fix it.

§ 02

How it works, in one picture

§ 03

Words you'll meet

a tiny glossary
Claude Code

The Claude app you chat with. It can use programs on your computer when you allow it.

Plugin

An add-on that teaches an app a new skill. This one teaches Claude to use Rhino.

MCP

The shared language AI apps use to talk to other programs. Like USB, but for software.

Terminal

A window where you type commands instead of clicking. You'll use it once, to install.

Node.js

A free helper program the plugin needs. Install it once, then forget about it.

Set it up once. field notes · 2 / 3

Four steps, about ten minutes. You only do this the first time. Copy the grey text exactly as it is.

1

Install Node.js

  1. Go to nodejs.org and download the version marked LTS.
  2. Open the file you downloaded.
  3. Click Next on every screen, then Finish.
You'll see

Nothing special happens afterwards. That's normal: it works in the background.

2

Add Rhino's connector

  1. Open Rhino 8. In the command line at the top, type _PackageManager and press Enter.
  2. Search for Rhino-MCP-Platform and click Install.
  3. Close Rhino and open it again.
You'll see

Rhino-MCP-Platform in the Installed list of the Package Manager.

3

Add the plugin to Claude

  1. Open a terminal. Windows: Start menu, type PowerShell, open it. Mac: press ⌘ Space, type Terminal.
  2. Copy the first line below, paste it, press Enter. Then do the same with the second line.
claude plugin marketplace add filippovisentin/claude-rhino-plugin
claude plugin install rhino@claude-rhino
You'll see

A line ending in Successfully installed plugin. You can close the terminal.

4

Say hello

  1. Open Rhino first, and leave it open.
  2. Start a new session in Claude Code.
  3. Ask: “What's in my Rhino document?”
You'll see

Claude lists your layers and objects. If Claude asks for permission, read the request and click Allow.

From now on

Open Rhino, then open Claude, and just ask. That's the whole routine.

§ 05

If it doesn't work

most common fixes
What happensWhat to do
Claude says it can't reach Rhino.Make sure Rhino is open. Then start a new Claude session.
Claude says the router or connector is missing.Step 2 didn't finish. Install Rhino-MCP-Platform again and reopen Rhino.
The terminal says claude or node is not recognised.Close the terminal, open a new one and try again. If it persists, redo step 1.
You get a long block of letters instead of a picture.You're in an old session. Start a new one.
Still stuck?Ask Claude: “Rhino isn't connecting, can you check?” It runs a check and explains the fix.
§ 06

Play it safe

four habits

Read before you allow

Claude asks before running anything in Rhino. Click Allow only if the request matches what you asked for.

Save a copy first

Before big changes, save your file under a new name. If you don't like the result, you can always go back to it.

Files from strangers

Text hidden inside a model is read by Claude. Be careful with models you didn't make.
